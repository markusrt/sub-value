Read this first

  • Ceilings, not typical bills. Values price a plan's full monthly limit. Most people use a fraction of the pool.
  • Value depends on the model. One plan is worth very different amounts on Sonnet, Opus or Fable (or Sol vs Astra). Claude plans let Fable use only half the limit.
  • API-equivalent ≠ lab cost. List API prices are not the same as a lab’s marginal cost of serving a subscription token.
  • Harness matters. Claude Code vs Codex vs Cursor change tokens per task, so equal API-equivalent value does not mean equal work done.
  • Grok is opaque. SuperGrok shows a shared weekly % pool with no official dollar size — numbers are reverse-engineered and low confidence.

Methodology

SemiAnalysis subscription study (October 2026)

SemiAnalysis measured how far each plan's usage meter moves per million tokens of each type (input, cached input, cache writes, output) for every model, then priced the full monthly limit at first-party API list rates. Headline values on the $200 tier (agentic workload):

  • Claude Ultra (was Max 20×) · Sonnet 5.5 → $12,529 (62.6×)
  • Claude Ultra · Opus 5.5 → $11,726 (58.6×)
  • Claude Ultra · Fable 5.1 → $2,485 (12.4×, half the plan)
  • ChatGPT Pro 200 · GPT-6 Astra → $2,897 (14.5×)
  • ChatGPT Pro 200 · GPT-6.1 Sol → $2,084 (10.4×)

On the models each lab pushes as the daily driver (Opus 5.5 vs GPT-6.1 Sol), Claude plans offer roughly 5× the API-equivalent value. OpenAI halved the $200 plan's tokens per model and added a $500 tier; Anthropic raised Opus limits (~20% on Max, ~50% on Pro) alongside the Opus 5.5 price cut, which still lowered the dollar value slightly. On Oct 30, 2026 Anthropic renamed Max 5× to Max and Max 20× to Ultra (same prices and weekly limits; verified Ultra accounts no longer have a five-hour limit).

What changed since the June 2026 study

The June drain experiment reported one number per plan (Claude $400 / $2k / $8k; ChatGPT $700 / $3.5k / $14k). Those figures are superseded: OpenAI's limits were cut, both labs changed API prices, and the October method prices each model separately.

Other providers on this site

MiniMax / GLM rows come from SemiAnalysis via a secondary summary (the section is paywalled); Kimi plans were measured at ~2.5–6.7× but no dollar figures are public. Cursor / Copilot are credit / pass-through products (~1–2× sticker), not lab-style flat-rate subsidies. Gemini rows use community aggregators (medium/low confidence). SuperGrok has no official dollar pool — show the range, not just the midpoint. These four providers have not been re-checked since July 2026.

Grok / SuperGrok

xAI bills SuperGrok as a shared weekly compute pool (Chat, Imagine, Voice, Build) displayed as percent used. Official docs do not publish a dollar size. Low estimates reverse-engineer token % against Grok 4.5 list rates ($2 / $6 per 1M short context). High figures are informal “value framing,” not drain experiments. Extra Usage Credits after the pool are priced at higher “standard rates” than included usage.
